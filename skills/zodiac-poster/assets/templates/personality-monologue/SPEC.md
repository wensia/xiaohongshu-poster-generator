# 性格独白风 - AI 生成规范

## 一、模板概述

| 属性 | 值 |
|------|-----|
| 风格 | 温暖治愈、深度解读、书信感 |
| 语气 | 第一人称独白、亲切口语化 |
| 适合话题 | 性格分析、情感表达、内心独白、减压方式、社交模式 |
| 不适合 | 星座配对、互动投票、测试题、运势预测 |

### 设计特征
- PART 标签分章节
- 左边框引用块
- 渐变暖色背景 (#FAF6F1 → #F0E6D9)
- 强调色 `#C4653A`

## 二、内容格式规范

### 2.1 封面 (cover)

| 字段 | 字数范围 | 格式要求 | 高亮规则 | 示例 |
|------|----------|----------|----------|------|
| 副标题 | 4-8字 | 形容词短语，概括特征 | 无 | 唯独受不了委屈 |
| 主标题第一行 | 6-12字 | XX座+主题词 | 1个【】 | 射手座什么【苦】都能吃 |
| 主标题第二行 | 4-8字 | 转折/递进语 | 1个【】 | 却扛不住【心寒】 |
| 标语第一行 | 6-10字 | 表象描述 | 无 | 看起来没心没肺 |
| 标语第二行 | 6-12字 | 本质揭示 | 1个【】 | 其实【心思细腻】 |

**封面高亮原则**：
- 主标题高亮**核心名词或动词**（表达主题冲突点）
- 标语高亮**情感词或特质词**
- 两个高亮词形成**表里对比**或**转折呼应**

**封面示例**：
```
副标题: 唯独受不了委屈
主标题: 射手座什么【苦】都能吃\n却扛不住【心寒】
标语: 看起来没心没肺\n其实【心思细腻】
```

### 2.2 内页 (page) × 4-6 页

| 字段 | 字数范围 | 格式要求 | 高亮规则 |
|------|----------|----------|----------|
| 章节标签 | 固定 | PART 01/02/03... | 无 |
| 章节标题 | 4-8字 | 名词短语或动词短语 | 无 |
| 正文 | 4-6行 | 每行5-15字 | 至少1组【呼应词】 |
| 引用 | 8-20字 | 金句，双引号包裹 | 可选0-1个 |

**内页高亮原则**：
- 每段正文必须有**至少1组高亮词**
- 两个词形成语义呼应：
  - **对比**：【直觉】vs【脑子】
  - **递进**：【想】→【做】
  - **因果**：因为【感觉】所以【选择】
  - **转折**：表面【冷】内心【热】
- 高亮词**不要连续**，中间需有普通文字间隔

**内页示例**：
```
章节标签: PART 01
章节标题: 表面乐观
正文:
射手表面乐观
其实内心【敏感】得要命
只是不想给别人添麻烦
习惯了【自己扛】
引用: "走得洒脱，是因为早就做好了准备"
```

### 2.3 结尾页 (summary)

| 字段 | 字数范围 | 格式要求 | 高亮规则 |
|------|----------|----------|----------|
| 章节标签 | 固定 | EXTRA | 无 |
| 章节标题 | 4-8字 | "写给XX座"格式 | 无 |
| 总结正文 | 3-5行 | 每行8-14字 | 1-2个【】 |
| 祝福语 | 2行 | 每行8-14字，斜体风格 | 可选0-1个 |

**结尾页原则**：
- 总结正文与封面主题呼应
- 高亮词承接封面的情感主线
- 祝福语是情感升华，语气温暖治愈

**结尾页示例**：
```
章节标签: EXTRA
章节标题: 写给射手
正文:
你不是不在乎
只是【太懂事】
不想让人为难
希望每个射手都能被【温柔以待】
祝福语:
愿你眼里有光
心中有梦
```

## 三、文案风格指南

### 3.1 语言风格
- **视角**：第一人称（"我们XX座"、"射手就是这样"）
- **语气**：口语化、亲切、有共鸣感
- **句式**：短句为主，节奏感强
- **禁忌**：避免书面语、长句、生硬描述

### 3.2 话题适配示例

| 话题类型 | 封面主标题示例 | 内页章节示例 |
|----------|---------------|-------------|
| 性格特质 | 射手座什么【苦】都能吃\n却扛不住心寒 | 表面乐观、内心敏感、习惯独撑 |
| 做决定 | 射手座做【决定】\n来不及想 | 选择的时候、犹豫的时候、果断的瞬间 |
| 减压方式 | 射手座的【减压】\n靠走 | 累了就走、一个人待着、不想解释 |
| 社交模式 | 射手座的【社交】\n看心情 | 聊天的时候、沉默的时候、独处的时候 |
| 恋爱 | 射手座【谈恋爱】\n一点就燃 | 喜欢的信号、暧昧期、确认关系 |

### 3.3 高亮词选择策略

| 呼应类型 | 说明 | 示例词组 |
|----------|------|----------|
| 表里对比 | 表象 vs 本质 | 【乐观】vs【敏感】、【洒脱】vs【细腻】 |
| 能力对比 | 能做 vs 不能做 | 【苦】vs【委屈】、【扛】vs【心寒】 |
| 行为对比 | 外在 vs 内在 | 【说】vs【想】、【走】vs【留】 |
| 递进关系 | 从浅到深 | 【累】→【走】→【好】 |
| 因果关系 | 原因 → 结果 | 【懂事】→【温柔以待】 |

## 五、SVG 渲染规范

### 5.1 配色系统

| 用途 | 色值 | SVG属性 |
|------|------|---------|
| 强调色/高亮 | `#C4653A` | fill |
| 主文字 | `#3D3835` | fill |
| 次要文字 | `#6B6461` | fill |
| 分隔线 | `#D4CFC8` | stroke |

### 5.2 字体规范

| 元素 | 字体 | 字号 | 字重 |
|------|------|------|------|
| 页眉星座名 | Noto Serif SC | 32px | 500 |
| 主题词 | Noto Sans SC | 24px | 300 |
| 封面主标题 | Noto Serif SC | 72px | 600 |
| 章节标题 | Noto Serif SC | 64px | 600 |
| 正文 | Noto Serif SC | 36px | 400 |
| 引用 | Noto Serif SC | 28px | 400 italic |
| 页码 | Georgia | 28px | 400 |

### 5.3 高亮词解析

**使用【】标记高亮词，渲染时转换为 SVG tspan：**

```python
import re

def parse_highlight(text: str) -> str:
    """将【词】转换为 SVG tspan 高亮"""
    def replace(m):
        return f'<tspan fill="#C4653A">{m.group(1)}</tspan>'
    return re.sub(r'【([^】]+)】', replace, text)

# 示例
# 输入: "其实内心【敏感】得要命"
# 输出: '其实内心<tspan fill="#C4653A">敏感</tspan>得要命'
```

## 六、检查清单

### 字数检查
- [ ] 封面主标题：第一行6-12字，第二行4-8字
- [ ] 内页正文：每行5-15字，共4-6行
- [ ] 引用金句：8-20字
- [ ] 总页数：5-9页

### 高亮检查
- [ ] 封面：3个高亮词（主标题第一行1个 + 主标题第二行1个 + 标语1个）
- [ ] 每个内页：至少1组呼应高亮词
- [ ] 结尾页：1-2个高亮词
- [ ] 高亮词不连续（中间有普通文字）

### 语义检查
- [ ] 高亮词形成呼应关系（对比/递进/因果/转折）
- [ ] 封面两个高亮词形成表里/能力/行为对比
- [ ] 引用与正文主题契合
- [ ] 祝福语与封面情感主线呼应

### 格式检查
- [ ] 页码格式 "0 X"（带空格）
- [ ] 章节标签 PART 01/02/... 或 EXTRA
- [ ] 正文行尾无标点符号
